# tools/noh

Converters and map importers that read data from [NoH](../../README.md#attribution),
Shawn Presser's K2 engine reimplementation (https://github.com/shawwn/noh): static and skinned K2 models to glTF,
prefab builders, and importers for NoH maps and forests. They take the path of
your own NoH game folder as an argument and write into your project; nothing
from NoH is stored in this repository.
